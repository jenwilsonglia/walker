# Walker
3D Printed Walker

**NOT FOR CLINICAL USE - 3D printed walker**

This project is still under heavy development and not for clincal use

**Introduction**

Mobility Aid devices experience a steep surge in need during mass casualty and increased trauma situations. This project creates a 3D printable walker that can be produced with commodity 3D printers and easily available wood dowels and screws.

**Acknowledgments**

This project is heavily based on work by the FAST lab at Western University in producing a 3D-printed walker.

[Project Page at OSF](https://osf.io/myh82/)

**Printing instructions**

PLA should not be used in production. Only PETG or ABS can be used.
